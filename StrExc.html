Calculation and saving help

Excavation CY = trench CY + flared-end CY.

Trench CY = [(diameter or span in inches + 24) ÷ 12] × pipe length × average excavation depth ÷ 27. For arch pipe, the first size is the span. Depth is total average excavation depth, not cover above the pipe.

FES means flared end sections (0, 1 or 2). Flared-end CY = FES count × the size allowance × depth. The Excel sheet includes the allowance and both calculation components.

Uses the recovered Mississippi DOT Structure Excavation v1.1 rules. The original EXE could not be run on this Windows system; calculations were checked against its extracted script. Check applicability to your project. This calculation does not add sloped trench walls, shoring or separate bedding allowances.

Rows display 3 decimal places. The project total displays 2, as in the original program, and sums unrounded quantities. Editing a row replaces its result.

Save project downloads a JSON file, including unfinished rows. Use Open project to reopen it and save again after edits. Closing this page does not save inputs. Opening another project asks before replacing unsaved changes.

Export Excel downloads a real .xlsx file with pipe inputs, formulas and totals. Open it in Excel to review or adjust the numeric inputs. Size and allowance are exported values; change pipe sizes in this app and export again. Keep the JSON file to reopen inputs in the app.
