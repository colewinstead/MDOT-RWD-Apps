Instructions & calculation basis

Select the slab drawing first, then a compatible rail and pavement detail. BE-1 and BE-2 use BER-1/BER-2 rails; SDBE-1 uses SDBER-1/SDBER-2; SDBE-1A uses the 9- or 12-inch SDBEPR detail. The legacy family preserves the original executable's 0/32/42-inch cases. Standard and special families have different surface and joint requirements.

Enter W1/W2 and skew, select the roadway pavement, and check the grooving pay item only when included in the project. Asphalt-covered concrete is excluded from grooving. SDBE-1 uses the exposed 3 ft strip normal to the skewed interface; bare SDBE-1A uses exposed pavement excluding rail footprints. Project totals keep bridge expansion joints, roadway expansion joints, bridge-plan joint/seal spans, and each rail height separate.

Save project downloads all inputs as a JSON file. Keep it separately and use Open project to continue. Save again after edits; closing does not save. Older project files reopen in the legacy family without changing their quantities. Export text downloads a report; Print / PDF uses the browser print dialog. Reports do not reopen as projects.

The standard sheets are the supplied August 2017 BE-1/BE-2/BER-1/BER-2 set. Special-sheet sources are retained snapshots from MDOT; several are preliminary/not for construction. Drawing-derived plan areas use the drawn perimeter and nominal side allowances; the equations are dimensional interpretations, not printed pay formulas. Verify the applicable contract, drawing revision, and project grooving limits. Schematics and reference sheets do not provide structural approval. This app calculates paving, grooving, joints, and rail lengths only.
