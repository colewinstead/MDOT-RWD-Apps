Instructions & calculation basis

Choose JB-1 or JB-2 for each box and select each pipe size. Enter skew in degrees and box height in decimal feet. Side 1 is outflow. Leave height blank for the calculated minimum. Save project downloads a JSON file; Open project restores it, including older JB-1 projects. Keep that file to retain your work. WK. SH. NO. identifies the plan sheet; BOX ID identifies the individual box. Export Excel includes both fields. Its steel, bar-length totals and project totals use formulas for manual adjustments. Change pipe geometry or box standards here and export again. Print / PDF includes every box and project totals; choose Save as PDF in the print dialog.

JB-1 uses recovered v5.0 geometry, concrete and bar rules from October 10, 2011, including unrounded circular deductions and the original arch lookup. Steel uses only the listed bars. These may differ from the rounded 2017 pipe-table deductions.

JB-2 uses MDOT drawing 6506, August 1, 2017. Circular pipes 48 inches and larger, or arch pipes 51 × 31 inches and larger, require all walls to be 8 inches; smaller pipes use the 8-inch deduction column whenever that happens. Otherwise walls are 6 inches. Maximum width is 9 ft 3 in. B/C/D bars are #6 for 6-inch walls and #7 for 8-inch walls; E/F are #6. Steel includes 3.3 lb for two lift bars.

JB-2 solid-wall counting convention: end bars are already included; add max(0, ceil(run / 12 inches) − 1) interior bars per solid wall. Use H for horizontal B/C bars and that wall's full width for vertical D bars. This is the user-confirmed interpretation of the 12-inch spacing note. Bar lengths retain precision. Unit weights: #4 = 0.668, #6 = 1.502, #7 = 2.044 lb/ft. Drawing applicability, structural adequacy, and opening conflicts require separate review.
