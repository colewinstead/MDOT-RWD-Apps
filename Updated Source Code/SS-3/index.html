Using this portable app

Open the single SS-3.html file in a current browser on Mac or Windows. No installation, server or internet connection is needed.

  1. Enter project information, then select an inlet type and pipe size. The height starts at the original listed minimum; enter the actual height in decimal feet.
  2. Add inlets to build the project schedule. Select an inlet to edit it. Changes update the quantities immediately.
  3. Save project downloads your inputs as a JSON file. Keep that file and use Open project to resume. Save again after editing; closing this page does not save your changes.
  4. Print / Save PDF creates a complete project report. Choose your browser’s Save as PDF destination for a PDF copy. Reports contain quantities, inputs and each inlet’s calculation breakdown.

Heights below the original listed minimum are blocked as a modern input safeguard. SS-4 reinforcement remains 31 lb at every accepted height, as in the original. The original SS-4 report does not list grate or frame weights; a dash means not reported, not zero.
