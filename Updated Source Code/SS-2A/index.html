Using this portable app

Open the single SS-2A.html file in a current browser on Mac or Windows. No server, installation or internet connection is needed.

  1. Enter project information, inlet dimensions in decimal feet, roadway side and pavement choice.
  2. Enter the pipe openings. Add inlets to build a project of up to 50 inlets.
  3. Save project downloads your inputs as a JSON file. Keep it and use Open project to resume. Save again after editing; closing the page does not save your changes.
  4. Print / Save PDF prints the project schedule and each inlet’s quantities and pipe deductions. Select your browser’s Save as PDF destination for a PDF copy.
