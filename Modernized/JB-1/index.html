JB-1 · Mississippi roadway design utility
Instructions & calculation basis

Enter pipe dimensions and wall thickness in inches, skew in degrees, and box height in decimal feet. Side 1 is outflow. Leave height blank for the calculated minimum. Save project downloads your inputs as a JSON file; Open project restores it. Keep that project file to retain your work. Print report includes all boxes and project totals.

Calculation basis: supplied JB-1 v5.0, revised October 10, 2011. Noncircular opening deductions use the original span-only lookup. Steel includes the original 4 lb allowance. Bar lengths retain calculation precision and display two decimals. Current MDOT compliance, structural adequacy, and opening conflicts are not evaluated.
